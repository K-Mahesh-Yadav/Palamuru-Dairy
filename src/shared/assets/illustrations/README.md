# Illustrations

Source: `Assets/` at the repo root. Copied here under short, meaningful names.
All are 663x450 with a transparent ground — see PLAN.md A7 and Risk 9: they
cannot be rendered larger than ~600 CSS px without going soft.

## Deliberately NOT copied

| Original | Why |
|---|---|
| `...is-mixing-water-in-milk-...` | Depicts milk adulteration. Brand-fatal for a "100% pure, no chemicals" dairy. |
| `...is-counting-the-money-...` | Money-counting undercuts the trust framing. |
| `...holding-money-...victory-sign-...` | Same. |
| `...is-holding-a-laptop-in-hand-...` | Redundant with `at-the-laptop.png`. Held in reserve. |
